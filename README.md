# Birmingham Airport Cars — Phase 1

Independent replacement front-end for `birminghamairportcars.co.uk`. This project does not connect to or modify the existing WordPress website.

## Stack
Next.js App Router, React, TypeScript strict mode, Tailwind CSS, ESLint, Vitest.

## Commands
- `npm install`
- `npm run dev`
- `npm run lint`
- `npm run typecheck`
- `npm test`
- `npm run build`

## Phase 1 boundaries
No production deployment, domain connection, payments, authentication, Google Maps or paid APIs.

## Pricing
Editable configuration is in `lib/pricing.ts`. Test journeys are in `lib/journeys.ts`.
